2. Довести кампанию: нарастающий распад, святилища, сундуки, элиты/симбиоты, зеркало и сохранение.
3. Улучшить читаемость интерфейса, мира, боя, обратную связь и звук.
4. Собрать Editor и Windows, выполнить C++ регрессии и автоматическое прохождение реальных карт.
5. Проверить изображения из игрового рендера и содержимое упакованного билда; записать ограничения.

## Ограничение инструмента

Прямое управление Windows через Computer Use не инициализируется: `codex/sandbox-state-meta: missing field sandboxPolicy`. Remote Desktop Commander подключён к тому же ПК. Исходники редактируются в папке открытого VS Code; для визуальной проверки используются штатные снимки игрового viewport.
