# ADR-20261101-001 -- Autonomous fallback prototype delivery

Status: IMPLEMENTED LOCALLY / NOT promoted to Unreal release / no canonical SoT change.

Context: Owner requested a fully playable Win64 Unreal game, live edits in VS Code and Codex SoT30. The target repository was empty; the remote desktop read operations timed out. The original design preferred Godot, while the latest requested execution surface was an Unreal installation. We could not verify either on the user's Windows host.

Decision: Build an independent no-dependency perspective-3D browser prototype as a verifiable interim vertical slice; bundle complete SoT30 sources and a Codex root AGENTS adapter. Keep native Unreal release status BLOCKED. Preserve the ability to port the tested rules without copying an unverified engine tree.

Alternatives: (A) write untested Unreal source and call it built (rejected as false readiness); (B) stop without code (rejected as avoidable zero-progress); (C) download/import all ten suggested libraries (rejected as uncontrolled complexity and license risk).

Consequences: Real playable browser loop with 3D geometry, but no UE-specific character animation, cinematics, navmesh, third-person camera controls, professional world assets or native Windows EXE. The new fallback is not a replacement for the target project.

Tests: `node tests/data.test.js`; browser smoke tests; `python tools/verify_sot30.py`; package SHA receipt. Any future Unreal port requires host read-back and UAT launch QC.

Diff scope: new standalone `LastLightWeb/` artifact only. Does not write or delete user `E:\LastLightUnreal`, rewrite SoT30, change tool policy or modify Supabase.

Rollback: remove the standalone fallback artifact or revert the isolated GitHub feature branch if published. Do not change an existing local Unreal project unless separately inspected.

Delta: functional vertical slice created. D: local tests and artifacts. Omega: 0.85 for verified local logic, 0 for native Windows packaging. Lambda: revise when desktop file read and executable launch produce fresh evidence.
